# To-Do List Android Application

## Project Overview

Developed a simple Android application for creating and managing daily tasks.

## Technologies Used

- Kotlin
- Android Studio
- XML Layouts
- RecyclerView
- SharedPreferences

## Features

- **Add Tasks:** Create new tasks for daily activities.
- **Complete Tasks:** Mark tasks as completed.
- **Delete Tasks:** Remove tasks when they are no longer needed.
- **Dynamic Task Display:** Display tasks dynamically using RecyclerView and Adapter.
- **Local Storage:** Save and retrieve task information using SharedPreferences.

## Implementation

- Designed the application interface using XML layouts and Android UI components.
- Implemented task addition, completion, and deletion functionality using Kotlin.
- Used RecyclerView and Adapter to display tasks dynamically.
- Used SharedPreferences for local data persistence.
